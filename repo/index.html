asus-numpad 1.2.4

ASUS 触摸板数字小键盘（NumberPad）的 Linux 用户态驱动 · GPL-3.0-or-later

本页是软件源根地址：https://raw.githubusercontent.com/RunningVAN/asus-numpad/main/repo。下面的命令直接可用，无需下载密钥。

Debian / Ubuntu / Mint

echo "deb [trusted=yes] https://raw.githubusercontent.com/RunningVAN/asus-numpad/main/repo/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/asus-numpad.list
sudo apt update && sudo apt install asus-numpad

仓库未做 GPG 签名，因此用 trusted=yes。介意的话请改用 Release 里的 .deb 手工装。

Fedora / RHEL / Rocky / openSUSE

sudo tee /etc/yum.repos.d/asus-numpad.repo <<'EOF'
[asus-numpad]
name=asus-numpad
baseurl=https://raw.githubusercontent.com/RunningVAN/asus-numpad/main/repo/rpm/$basearch
enabled=1
gpgcheck=0
EOF
sudo dnf install asus-numpad

Arch / Manjaro

sudo tee -a /etc/pacman.conf <<'EOF'

[asus-numpad]
SigLevel = Optional TrustAll
Server = https://raw.githubusercontent.com/RunningVAN/asus-numpad/main/repo/arch/$arch
EOF
sudo pacman -Sy asus-numpad

Alpine

echo "https://raw.githubusercontent.com/RunningVAN/asus-numpad/main/repo/alpine/$(apk --print-arch)" \
  | sudo tee -a /etc/apk/repositories
sudo apk update && sudo apk add --allow-untrusted asus-numpad

Nix / NixOS

nix run github:RunningVAN/asus-numpad
# NixOS: services.asus-numpad.enable = true;

其它发行版

用 Release 里的通用 tarball（musl 静态链接，任意 x86_64 Linux 可跑）：

tar xzf asus-numpad-1.2.4-x86_64.tar.gz
cd asus-numpad-1.2.4 && sudo ./install.sh

内容

路径说明
apt/APT 仓库（dists/stable + pool）
rpm/<arch>/RPM 仓库（含 repodata）
arch/<arch>/Pacman 仓库（asus-numpad.db）
alpine/<arch>/Alpine 仓库（APKINDEX）

每个生态只保留最近 3 个版本；更早的版本仍可从 GitHub Releases 取。
