# 真机验证记录

基准机：ROG Strix SCAR（G634JY / Fedora 44），触摸板 `ASUE1416:00 04F3:3275`，背光节点 `/dev/hidraw4`。
验证版本 1.0.0-19 起，1.0.0-22 复验。

## 方法

手按真触摸板时无法同时抓报文，因此：

1. 用 `uinput` 造一块参数相同的虚拟触摸板（同名 device、同 `04F3:3275`、同分辨率几何），
   交给驱动状态机处理；
2. 在服务进程上挂 `ptrace` 拦截对 `/dev/hidraw4` 的 `write`，记录真正发往硬件的字节。

## 结果

| 动作 | 观测事实 | 说明 |
| --- | --- | --- |
| 长按图标区 (3511,379) 共 90 帧 | 状态机 `numlock → fired → enabled=true`；内核级抓到 `write(/dev/hidraw4, "0d 14 03 01 ad", 5) = 5` | 长按判定与 FEATURE 下发链路通 |
| 同上，键盘背光 3 档 | 抓到 `0d 14 03 48 ad` | 键盘背光 → 数字区 8 档归一化生效 |
| `bright 1 / 2 / 3`（1.0.0-22） | `bright status` 输出 `0x43 / 0x46 / 0x48` | 手动档与跟随映射一致 |
| `bright follow on/off` 切换（1.0.0-22） | 亮度无跳变 | 两套换算共用同一映射 |

## 未覆盖

- **再次长按关闭**：注入脚本里的第二次长按未被识别，没抓到 `0d 14 03 00 ad`。
  `uinput` 帧序列与真实手指有差异，此路径需人工在真机上确认（手工长按观察到状态行
  显示「背光熄灭 / 数字键盘关闭」）。
- **回读**：该 FEATURE 报告用 `HIDIOCGFEATURE` 回读恒为全 0，设备不提供回读，
  「灯亮没亮」无法用设备侧回读作证，物证仅为上述写入报文与驱动状态行。
- **i2c 通道**：老机型未做同类验证。

## 装包权限验证

1.0.0-18 修复 `%post` 漏 `udevadm trigger --subsystem-match=hidraw` 的问题后，
装包即生效，无需重启：`getfacl /dev/hidraw4` 可见 `user:goog:rw-`，
服务 `linger=yes` 开机自启。
